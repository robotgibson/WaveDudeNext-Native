# Open-Source Software and Mathematical Attributions

WaveGuide Native C++ Pro Studio is built upon, inspired by, and derived from the following incredible open-source projects, algorithms, and creators:

## 🔬 Core Physics & Concept Lineage
*   **Jeroen Vleggaar (Huygens Optics)**
    *   *Contribution:* Original creator of **Wave Dude 2D**, which pioneered the innovative 24-bit RGB bitmap simulation canvas semantic mapping (Red: Refractive Index, Green: Sine Emitters, Blue: Damping Absorption).
    *   *Reference:* [Huygens Optics YouTube](https://www.youtube.com/@HuygensOptics) | [huygensoptics.com](https://huygensoptics.com)
*   **0x23 (Diffraction Limited)**
    *   *Contribution:* Author of **WaveSimulator2D**, demonstrating high-speed FDTD grid computations and unique color-field blending mapping logic.
    *   *Reference:* [GitHub Repository](https://github.com/0x23/WaveSimulator2D)
*   **Alexander Gräf**
    *   *Contribution:* Author of **WaveDudeNext**, which successfully expanded the original 2D wave optics workflow to support multi-channel probes, live geometric transformers, and logic gating circuits.
    *   *Reference:* [GitHub Repository](https://github.com/graealex/WaveDudeNext)

## 🎛️ Software Engineering Frameworks & Libraries
*   **Dear ImGui (Omar Cornut)**
    *   *Contribution:* Immediate-mode graphical user interface library used to drive our entire multi-channel studio tuning desk sidebar, precision sliders, oscilloscope trace plots, and logic level readouts.
    *   *Licensing:* **MIT License**
    *   *Reference:* [GitHub Repository](https://github.com/ocornut/imgui/)
*   **Simple DirectMedia Layer 2 (SDL2 & SDL_image)**
    *   *Contribution:* Cross-platform window shell management, hardware rendering contexts creation, device input polling, and native compressed PNG texture asset file streaming codecs.
    *   *Licensing:* **Zlib License**
    *   *Reference:* [libsdl.org](https://libsdl.org)
*   **OpenMP Multi-Processing Standard**
    *   *Contribution:* Shared-memory compiler compiler directive architecture used to parallelize our finite-difference time-domain (FDTD) wave grid calculation loops across all physical CPU thread cores.
    *   *Reference:* [openmp.org](https://openmp.org)

We owe a massive thank you to these developers and communities for making high-performance graphics and computational photonics engineering accessible to the open-source world!
